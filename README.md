📈 Angry Traders Dashboard

A modern AI-powered trading dashboard built with TypeScript, Vite, and React, designed to provide traders with a clean interface for market insights, analytics, and trading-related data visualization.

This project focuses on creating a fast, responsive, and interactive dashboard experience with modern UI components and scalable frontend architecture.

⚙️ Installation & Setup

1️⃣ Clone the Repository

git clone https://github.com/UnmeshOnGit/AngryTradersDashboard.git

2️⃣ Navigate to Project Folder

cd AngryTradersDashboard

3️⃣ Install Dependencies

npm install


---

🔑 Environment Variables

Create a .env.local file in the root directory.

Example:

GEMINI_API_KEY=your_api_key_here


---

▶️ Run Locally

Start the development server:

npm run dev

The app will run on:

http://localhost:5173


---

🏗️ Build for Production

npm run build

Preview production build:

npm run preview
